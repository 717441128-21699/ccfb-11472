# DataProbe：数据画像与漂移监控系统

面向数仓日常灌表场景：自动给每张表做每日画像，监控字段含义变化、空值异常、
分布漂移，并通过 Web 管理页面呈现来源、画像、事件与阈值。

## 功能清单

| 需求 | 实现 |
| --- | --- |
| 三类数据源 + 类型推断 | CSV 逗号文本、Parquet、SQLite；统一转字符串后由 `infer.py` 推断 boolean/integer/float/datetime/text |
| 每日画像 | 空值率、基数/去重率、数值分布（分位数+直方图）、最值、文本格式模式 |
| 文本格式归纳 | 结构签名（数字→9、字母→a、汉字→中）+ 语义标签（电话/证件/邮箱/编码等） |
| 漂移检测 | 数值 PSI + KS、类别 PSI、格式 PSI、空值率稳健 z、基数/去重率、范围偏移、布尔占比、行数 |
| 季节性免疫 | 基线优先取“同星期”历史快照，小样本日跳过分布类指标 |
| 列改名/移位识别 | stable_col_id 稳定身份 + 名称/类型/位置/数据指纹两阶段匹配 |
| 误报反馈 | 事件标误报后生成签名规则，同类事件后续自动降级（或抑制），命中次数可追踪 |
| 管理页面 | 来源登记、表画像、单列详情、漂移事件、阈值配置五个页面 |

## 目录结构

```
dataprobe/
  config.py       阈值与全局配置（可在页面覆盖）
  infer.py        类型推断、文本格式归纳
  connectors.py   CSV / Parquet / SQLite 读取
  profiler.py     单日画像（蓄水池采样，精确统计走全量）
  identity.py     列稳定身份与结构变更检测
  drift.py        PSI/KS、稳健 z、季节性基线
  storage.py      SQLite 元数据存储
  pipeline.py     日批编排（按 表+日期 幂等）
  web/            Flask 管理页面
scripts/
  simulator.py    30 表 × 60 天数据 + 22 个真值漂移
  run_pipeline.py 全量流水线
  run_web.py      管理页面启动
  demo_feedback.py 误报反馈演示
tests/
  evaluate.py     验收评估（漏报=0、误报≤5）
  test_infer.py   类型推断单元测试
```

## 快速开始

```powershell
py scripts/simulator.py          # 1. 生成模拟数据
py scripts/run_pipeline.py --reset   # 2. 跑 60 天画像与漂移检测
py tests/evaluate.py             # 3. 验收评估
py scripts/run_web.py            # 4. 打开 http://127.0.0.1:5000
```

## 漂移指标说明

- **PSI**（Population Stability Index）：分桶占比差异，<0.1 稳定、0.2 预警、0.4 严重。
- **KS**：两样本经验分布最大距离，对数值位置/形状变化敏感（实现与 `scipy.stats.ks_2samp` 对齐）。
- **稳健 z**：基于中位数与 MAD（中位绝对偏差），不被极端值和周末波动带偏。
- **同星期基线**：默认在参考窗口内只取相同星期几的快照比较，周末低流量不产生伪漂移。
  行数、基数这类对样本量敏感的指标，在同星期样本不足时直接跳过而非降级比较。

## 关键设计决策（误报控制）

1. **基数看口径分治**：高基数 ID 列用去重率（免疫行数缩放），低基数枚举列用绝对取值数。
2. **长数字串归文本**：手机号（11 位）、证件号（15/18 位）不推断成整数，才能做格式归纳与格式漂移。
3. **整数判定优先于布尔**：0/1 数值列在周末小样本下不会被误判成布尔列。
4. **列身份两阶段匹配**：同名列先锁定，改名/移位再靠数据指纹兜底；名称不同时指纹必须兼容，
   防止“新增的同类列”被误认成旧列。
5. **事件签名反馈**：签名 = `表|指标|稳定列身份`，标误报后同类事件自动降级，命中次数可追踪。

## 阈值调优

所有阈值集中在 `dataprobe/config.py` 的 `THRESHOLD_SCHEMA`，管理页面
“阈值配置”可按全局或单表覆盖，无需改代码、无需重跑即可调整（新快照生效）。
